PROJECT / HOTEL

Hotel Room Booking System

A web application that brings together guest registration, room booking, reservation status tracking, and a central booking dashboard.

What the project does

  • Register guest accounts and sign in.
  • Select rooms, dates, guest counts and optional services.
  • Calculate booking prices and check room availability.
  • Browse and filter reservations by booking status.
TechnologiesC# · ASP.NET Web Forms · HTML · CSS · JSON
