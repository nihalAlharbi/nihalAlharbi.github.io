Employee Input Validation

A focused Python desktop application that checks employee form inputs and communicates errors or successful validation through message dialogs.

What the project does

  • Collect first name, last name and employee ID.
  • Check first-name length, required last name and numeric ID.
  • Display clear success and error messages.
  • Practice form design and event handling with Tkinter.
TechnologiesPython · Tkinter · Input validation
